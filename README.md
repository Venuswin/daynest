# DayNest 🏡

🌐 **Live Demo:** https://venuswin.github.io/daynest/

A cozy life-recording prototype that turns daily memories into small objects in a virtual room.


## About

DayNest is a cozy, no-pressure life-recording room prototype inspired by *Animal Crossing* and *Stardew Valley*.

Instead of asking users to write a diary from a blank page, DayNest lets them bring small pieces of their day into a virtual room. A book, fruit, drink, homework paper, or even a bad mood can become a small memory object.

The project explores a softer form of self-recording: no streaks, no reminders, no productivity pressure, and no guilt for not returning every day.

## Features

- Cozy interactive room interface
- “Bring today home” memory-recording flow
- Bilingual UI: English / 中文
- Time-based room atmosphere
- Memory objects in the room
- Scrapbook archive for past memories
- Gentle follow-up card for yesterday’s memory
- Local saving with `localStorage`
- Built with HTML, CSS, and JavaScript

## Design idea

DayNest asks:

> What if journaling felt less like completing a task, and more like coming home?

It is not a productivity app, habit tracker, or social platform. It is a small, cozy space for everyday memory-making.
